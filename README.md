# INFR 3120: Portfolio Website

## Overview of the Project
This is my personal portfolio website that I made for an assignment, which is for my iNFR3120 course on web and script programming.

The website includes 4 pages
- Home
- About Me
- Projects
- Contact Me

## Technologies Used
 - Node.js
 - Express.js
 - EJS
 - HTML and CSS
 - Font Awesome
 - Bootstrap
 - Javascript

## Organization 
 - Public: Image files, JavaScript, and CSS
 - Routes: Has Express routes for each page
 - Views: Has the website's EJS templates
 - Views/partials: The navigation bar, shared header, and footer
 - app.js: The Express application is configured here
 - server.js: Starts the web server

 ## How to Run
 1. Download or clone the repository
 2. In a terminal, open the project folder
 3. To install dependencies, run npm install
 4. To launch the server, run npm start
 5. Launch a browser and naviagte to http://localhost:4000/home
